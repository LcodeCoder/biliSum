# biliSum

当前版本：**0.1.19**。

一个独立的 Chrome / Edge 浏览器扩展：点击工具栏图标，在 B 站视频旁打开原生侧栏，整理思维导图、Markdown / HTML 阅读页和字幕。

## 0.1.19 全宽阅读与数学排版

整个插件与 Markdown 正文随窗口宽度展开，移除工作台和正文的固定宽度上限，保留窄侧栏间距。行内公式自然对齐正文基线；单个大写命题的否定使用上横线表示，可带下标，不等关系和复合式的否定保留原写法。

浏览器工具栏、扩展管理页与侧栏 favicon 统一使用黄色手绘导图标识。图标源文件与生成脚本随源码提供。

实际预览：[宽窗口笔记](docs/fluid-markdown.png)、[窄侧栏公式](docs/math-inline-380.png)。

## 0.1.18 导图阅读与公式修复

保留手绘笔记本风格，导图默认按 1 倍阅读，展开节点时保持当前字号，只平移到相应内容。分支间距随可见结构高度温和拉宽，长标签有更宽的文字区，下级正文增至 15px，减少陡直连线和碎行；查看完整结构仍可点击「适应画布」。

Markdown 笔记与 HTML 阅读页支持行内和独立公式，也兼容旧缓存中丢失标记反斜杠的明确括号式公式。公式使用 KaTeX 数学字体，正文继续使用手写字体；排版样式与字体随扩展和单文件 HTML 内嵌，可离线阅读。

实际预览：[导图概览](docs/adaptive-mindmap.png)、[导图原始大小阅读](docs/adaptive-mindmap-reading.png)、[数学笔记](docs/markdown-math.png)。

## 安装到 Chrome

从 GitHub 下载或克隆的是源码，先在项目目录中构建（Node.js 22.12 或更新版本）：

```sh
git clone https://github.com/LcodeCoder/biliSum.git
cd biliSum
npm ci
npm run build
```

构建会生成 `dist` 安装目录。已经拿到 ZIP 安装包时，直接解压后继续以下步骤。

1. 打开 Chrome，地址栏输入 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本项目下的 **dist 文件夹**：

```text
项目目录/dist
```

这个目录里应当直接看到 `manifest.json`。选择项目根目录会报缺少清单。ZIP 安装包请先解压，再选择包含 `manifest.json` 的目录。

5. 在 Chrome 右上角的拼图菜单中找到 **biliSum** 并固定。
6. 打开 B 站视频，点击 biliSum 图标，侧栏会与视频并排显示。

已安装旧版时，在 `chrome://extensions` 找到 biliSum 并点击刷新图标，再关闭并重新打开侧栏。API 配置保留。0.1.3–0.1.18 升级到 0.1.19 可继续读取已完成的结果缓存；0.1.2 及更早版本的结果缓存使用不同的字幕标识，不会自动恢复，请在升级前导出重要结果。

最低 Chrome 版本为 120。侧栏宽度可以拖动边界调整；显示在左边时，可在 Chrome 的侧面板设置中选右侧。

## 没有字幕的视频

打开视频后，在「从音频生成字幕」中选择语言，点击 **识别视频音频**。扩展按当前分 P 的 CID 获取完整独立音轨，在本机转写；完成后即可生成思维导图、Markdown 总结和 HTML 阅读页。首次读取时可使用 B 站字幕；已有当前分 P 的本地识别缓存时会恢复本地结果。没有取得完整音轨时，也可导入与当前分 P 时长一致的音频，或导入已有字幕。

- **自动**：所选语言的浏览器本地识别已经可用时优先使用；否则使用 Whisper Base 本地模型。内置识别中途失败时，从头使用本地模型识别整段音频，丢弃前次部分结果。
- **本地模型**：支持中文、英语、日语、韩语和自动语言检测，提供时间轴、SRT 下载和时间跳转。首次下载约 150 MB 固定版本模型，之后复用浏览器缓存；网络必须能访问 Hugging Face 及其模型文件域名。缓存被浏览器清理后需重新下载。运行脚本及 WebAssembly 随扩展打包。
- **浏览器内置**：仅使用支持 `processLocally` 和明确音频轨道输入的实现。可点击安装本地语言包；处理时间至少与音频时长相当。浏览器没有返回精确时间轴，因此只提供 TXT 和资源生成；需要 SRT 或时间跳转时选择本地模型。

Chrome / Edge 的 Live Caption 浮窗文字没有作为扩展输入使用；扩展检测可用的本地语音 API，不依赖浮窗状态或远程免费转写接口。不同浏览器版本及语言包能力可能不同，不支持内置识别时可用本地模型。Edge 安装使用 `edge://extensions` 中的「加载解压缩的扩展」，选择同一 `dist` 目录。

支持最多 **4 小时、128 MiB（界面显示 128 MB）** 音频。压缩音频完整下载后按短窗口解码，不把整部长视频展开为巨大的 PCM 缓冲；本地模型在独立线程运行。取消、超时、音频缺口或切换分 P 均停止旧任务，只接受完整结果，保留当前视频原有字幕和资源。识别文本可能出现错字、漏字或时间偏差，请结合视频核对。

下载视频音轨得到的完整转写单独缓存，最多 12 条、约 2 MB，按视频、CID、语言及引擎隔离；导入音频的转写不持久缓存。转写本身不需要 API Key，不按使用量收费；点击生成资源仍沿用现有 AI 配置及其计费规则。首次识别会申请音频和模型下载域名权限，音频不上传至转写服务，也不使用麦克风。

## HTML 阅读页

HTML 和思维导图、Markdown 一样，是独立的 AI 生成类型。获取字幕后点击 **生成阅读页**（窄侧栏）或 HTML 阅读页右侧生成按钮（宽窗口），也可进入阅读页点击「用 AI 生成阅读页」，模型直接分析当前视频字幕，给出核心结论、内容章节、适合的对比表格以及可选主题结构，再由 `answer-me-with-html` 技能的本地适配版排版。无需先生成 Markdown 或思维导图。

支持卡片概览 / 长文阅读、简洁 / 纸张 / 蓝图三种排版样式和专注阅读，默认使用纸张样式。页面跟随扩展的浅色、护眼或深色外观；三种样式保留排版差异并共用当前色板。只有生成和重新生成请求 AI；切换样式、外观、版式、查看缓存及下载均在本地完成。长字幕沿用分段笔记、队列和冷却策略，最终生成按服务商规则计费。

点击下载图标保存单个 `.html` 文件，用浏览器直接打开即可阅读，无需联网或安装扩展。生成失败、返回格式错误或取消时保留上次完整阅读页；不把未完成的 JSON 当作阅读页导出。已完成的 HTML 内容独立缓存，切换视频或字幕来源会清除旧结果。主题条目分布只按本页结构中的真实节点数计算，不代表视频时长或重要性。

导出文件不含脚本、远程资源或 API 配置；原视频和正文中的 HTTP(S) 链接仅在手动点击时打开。阅读页保留分析内容和视频信息，分享前可自行检查其中的内容。

## 数学公式

Markdown 笔记与 HTML 阅读页支持四种标准标记：行内 `$...$`、`\(...\)`，以及独立成行的 `$$...$$`、`\[...\]`。旧缓存中的 `(X\in\mathbb{R})`、`(A=0)` 等明确数学表达式也可恢复排版；普通说明括号和代码保持原文。

公式使用 KaTeX 的专用数学字体，保留分数、上下标、根号和符号的比例，作为手写字体规则的例外。行内公式自然对齐正文基线。单个大写命题的 `\neg` / `\lnot` 显示为上横线，例如 `\neg A` 显示为 `\overline{A}`，也支持 `B_n` 等带下标的命题；不等关系和复合式的否定保留原写法。宽公式在自身区域横向滚动；扩展和导出的单文件 HTML 均内嵌公式样式与字体，无需联网。

## 配色与护眼模式

右上角太阳、眼睛、月亮分别切换浅色、护眼、深色外观，选择会保存在本地。浅色使用奶白笔记纸和墨色文字，护眼模式使用暖米色，深色模式使用深橄榄纸色与浅色文字。三种外观都保留虚线、手绘小圆角和记号笔点缀；按钮悬停轻微倾斜，按下时压平，键盘焦点使用清晰虚线轮廓。系统设置减少动态效果时停用交互动效。

界面控件、下拉框、表格、Markdown 预览、字幕、导图 / 大纲 / 分布和 HTML 阅读页共用一套色板。切换时保留导图的展开状态和浏览位置，已有结果立即更新样式，不需要重新请求 AI。SVG、PNG 和离线 HTML 跟随下载时的外观；`.md` 是纯文本，配色由打开它的阅读器决定。

## 第一次使用

点击侧栏右上角的齿轮图标，填写：

- **API 地址**：OpenAI 兼容的服务域名、基础路径（例如 `https://your-api.example/v1`），或完整 `/chat/completions` 地址。只填域名时自动补全 `/v1/chat/completions`；明确填写的路径会保留。设置页显示实际请求地址。
- **API Key**：自己的服务密钥。
- **模型名称**：服务商提供的模型 ID。

点击「测试连接」检查接口，点击「保存设置」应用。首次保存或测试时，Chrome 会询问是否允许访问你填写的 API 域名。修改地址后需要重新保存。测试连接会发送一次简短模型请求，按服务商规则计费。

使用本地 OpenAI 兼容服务时，地址可为 `http://localhost:11434/v1` 或 `http://127.0.0.1:端口/v1`；如果服务不校验密钥，可填写 `local`，并填写已安装模型的准确名称。

## 图标与页面

浏览器工具栏与侧栏 favicon 使用同一黄色手绘导图标识。扩展图标提供 16 / 32 / 48 / 128px 文件，源图为 `public/icons/source.svg`，运行 `node scripts/generate-icons.mjs` 可重新生成。

窄侧栏提供「生成导图 / 生成笔记 / 生成阅读页」三个文字操作；宽窗口在左侧资源列表中就地生成或重新生成，右侧查看详情。导出操作使用图标，鼠标悬停显示用途，同时提供键盘焦点与无障碍标签。页面导航和视图切换同时显示图标与文字，错误恢复、取消测试和返回完整总结使用文字按钮。下拉框与输入框共享字体、圆角、边框、箭头和焦点样式，支持浅色、护眼、深色三种外观。

- 上方**分支图标**：生成思维导图。完成后自动收起生成设置，支持**导图 / 大纲 / 分布**三种视图、按主题阅读、层级折叠、专注阅读，以及 **SVG / PNG / Markdown 大纲下载**。
- 上方**文档图标**：生成 Markdown 总结。总结页提供渲染预览、源码切换、复制、**.md 下载**。
- 下方 **HTML 图标**：独立请求 AI，把当前视频字幕整理成阅读页，支持卡片概览 / 长文阅读、简洁 / 纸张 / 蓝图三种排版样式、专注阅读和 **.html 下载**。生成和重新生成按服务商规则计费；样式 / 外观 / 版式切换和下载不新增请求。下载的是预览中的同一份文档，可离线打开。
- 下方**字幕图标**：进入字幕页，支持字幕来源选择、搜索高亮、跳转播放器时间、复制、**TXT / SRT 下载**。
- **上传图标**：导入 SRT、VTT、TXT 或 B 站字幕 JSON（`body: [{ from, to, content }]`）。TXT 没有时间轴，因此只提供 TXT 导出和基于文本的总结。
- **刷新图标**：重新读取当前视频与字幕。
- **方块图标**：停止当前生成。
- **太阳 / 月亮图标**：切换浅色 / 深色外观，自动保存选择。
- **齿轮图标**：API 设置。
- **GitHub 图标**：打开 [biliSum 仓库](https://github.com/LcodeCoder/biliSum)，欢迎点个 Star。悬停显示「GitHub · 求 Star」，设置页也可访问。

**总结细腻程度**：上方滑动条提供精简、简要、标准、细致、详尽五档，同时控制下一次 Markdown、思维导图和 HTML 阅读页生成。高档位保留更多论证、例子和细节，低档位聚焦主线；短视频按实际内容整理。修改滑动条后，重新点击相应生成图标即可应用。已生成结果继续显示其生成时的档位。

Markdown 正文铺满可用内容区，随窗口宽度伸缩；宽工作台使用随宽度变化的内距，窄侧栏保留紧凑间距。总结以连贯段落为主；比较、步骤、数据等适合表格的内容会按需加入少量表格。表格铺满文档宽度，字号与正文一致，使用加粗表头、交替行底色和清晰行列分隔；宽表在自己的区域内横向滚动，聚焦表格后也可用左右方向键移动。升级后已有总结会直接使用新样式，无需重新生成。思维导图点击父节点可展开下一层，再次点击收起；也可聚焦父节点后按回车或空格操作。以鼠标所在位置为缩放中心；方向键移动，加减键缩放，`Home` 或 `0` 恢复适应画布。切换外观时保留当前导图浏览位置，导出的 SVG / PNG 跟随下载时的当前外观，始终保留完整导图。

切换视频或分 P 时会中止旧任务，清理上个视频的字幕来源和结果。刷新当前视频时，本地识别或导入字幕会保留；新出现的 B 站字幕只加入来源列表，只有手动选择才替换当前内容。同一个分 P 内可在「字幕来源」中切回已识别或导入的字幕，资源按字幕内容和来源标识恢复，来源切换本身不请求 AI。导入字幕仅在当前侧栏会话保留。切换来源或刷新失败时保留原字幕与已生成结果，显示失败原因并允许重试。

生成失败或主动停止后，已收到的 Markdown 会保留为**未完成草稿**，可复制或下载，文件中也会注明内容不完整；有上次完整总结时可切回查看。草稿仅在当前侧栏会话中保留，不写入完整结果缓存，关闭侧栏、切换视频或更换字幕前请先下载。重试由用户点击触发，会重新发起模型请求，可能产生新的费用。

短字幕只请求一次最终结果。长字幕先逐段生成笔记，必要时多轮合并，再请求最终结果；总结和导图共用这一步的已完成笔记。生成前显示分段数量与多次请求提示，进度栏显示当前阶段。最多缓存最近 12 个视频的完整结果，采用约 6 MB 的 JSON 预算；空间不足时优先清理较早结果。缓存失败不影响查看与下载。多个侧栏保存时串行合并，避免互相覆盖。

## 导图阅读与图表

默认先展示一级主题，选择一个主题后展示它的要点；可切到全部层级。所有侧栏宽度和 SVG / PNG 导出统一从左向右展开。初始按 1 倍阅读；中心主题过长、无法放入窄侧栏时才缩至容纳中心主题的比例。展开或聚焦节点保持当前缩放比例，需要时以 220ms 平移显示内容；启用减少动态效果时直接定位。设置区可折叠，专注阅读会腾出上方信息区域，按 `Esc` 返回。百分比按钮可按原始大小阅读；「适应画布」查看全图。窄屏内容超出右侧时会提示拖动，亦可选择主题或使用大纲。

一级与后续分支的基础水平间距分别为 140px、100px；可见分支较高时温和拉宽，逐渐接近 440px、340px 的上限。一级与下级标签的文字宽度上限分别为 340px、420px，下级正文使用 15px 字号和 24px 行高。层级折叠和主题选择减少同时显示的节点，设置折叠与专注模式扩大阅读区域；手动缩小后仍可点击百分比恢复原始大小，再拖动查看细节。

- **导图**：查看主题关系，支持滚轮缩放、拖动平移、缩放按钮和键盘操作。
- **大纲**：按文字阅读所有条目，支持安全搜索、折叠、展开全部及完整 Markdown 大纲下载。
- **分布**：主题条目数量横条图、层级数量横条图及主题 / 条目 / 层级统计卡片。点击主题可跳到对应分支。统计只反映生成导图的结构，不代表时长或重要性。

三种视图切换保留阅读位置、搜索和折叠状态，不新增模型请求。SVG、PNG 和 Markdown 大纲始终导出完整导图，包含未展开及未选中的主题。

## AI 调用、费用与失败续读

总结、导图和连接测试使用同一个请求队列。同一 API 源一次处理一个请求，最小请求起始间隔为 3 秒，多个侧栏窗口共享队列与冷却时间；其他 API 源独立处理。队列等待不占用模型响应超时，排队超过 90 秒会给出重试提示；生成请求等待响应最多 180 秒，响应后连续 90 秒无数据会停止等待，整次请求最多 10 分钟，持续到达的思考或心跳数据可延续接收但不会突破总时限。连接测试仍为 30 秒。排队或控制频率时可停止，已取消的请求不会补发。

收到 HTTP 429 时遵循 `Retry-After`，缺失时冷却 30 秒；HTTP 503 带此头时也执行冷却。剩余冷却超过 30 秒会直接显示何时重试，较短等待显示倒计时。没有自动付费重试，队列存储故障时在发送前报错。

长字幕已成功的片段和合并笔记只缓存在当前侧栏内存中，闲置 30 分钟过期，最多 4 个输入、约 200 万字符；更换视频、CID、字幕来源、API 账户、模型或细腻程度会隔离笔记。同一配置下，失败重试会复用已完成片段；仅最终生成失败时可直接重发最终请求。生成总结后再生成导图同样可复用笔记，但每次最终生成仍会产生新请求。关闭侧栏、过期或缓存被淘汰后，会重新读取字幕；中断的半个片段不缓存。

Markdown、分段笔记、合并笔记和导图统一请求流式响应，同时兼容服务直接返回 JSON。Markdown 正文保留流式预览；笔记与导图只在内存中积累，结束标记与结构校验通过后才用于后续整理或替换图表。思考内容只更新阶段提示，不进入正文或导图，也不存入缓存。流式事件必须以空行封口，连接结束不会被当作完成标记。

进度提示区分等待响应、模型思考、接收正文和校验导图；不按每个心跳或思考片段重复更新正文。HTTP 408 / 504 / 524 明确提示未收到完整结果及可能已计费，不自动切换到非流式重发。错误页立即停止读取，可选 JSON 错误详情最多读取 5 秒。流式请求能改善脚本的接收路径，但不能保证服务转发数据或消除网关超时。

## 字幕获取

参考原项目 bilibili-copilot 的流程：

1. 从当前标签页 URL 识别 BV / AV 与分 P。
2. 调用 B 站 view 接口，选择当前分 P 的 CID。页面初始数据可作为经过视频标识校验的备用信息源。
3. 向 player 接口同时传入 BV、AV 和 CID；验证返回的 BV、AV、CID 及可用的分 P 标识。对失败或空列表尝试备用 player 接口，两个端点返回的身份均不匹配时拒绝加载。
4. 字幕轨道绑定当前视频身份，下载前再次核对，并检查字幕时间不超过当前分 P 的时长。请求绕过 HTTP 缓存。
5. 恢复或刷新本地识别 / 导入字幕后，仍可更新 B 站来源列表，但不会自动覆盖当前本地字幕。只有手动切换来源才下载替换。

扩展沿用浏览器的 B 站登录状态。部分视频只有登录后返回字幕；没有可用字幕时可识别当前分 P 的完整音轨，或导入已有音频 / 字幕。番剧、直播和短链接页面请先跳转到标准 `www.bilibili.com/video/...` 视频页。

## 数据与权限

完整的数据处理、存储、第三方传输与删除说明见 [隐私政策](PRIVACY.md)。

API Key 以普通字符串保存在当前浏览器配置的本地扩展存储中（不是加密保险库），仅向你配置的 AI 服务发送以完成鉴权，不跨设备同步。生成时，当前视频信息及字幕直接发送到你配置的模型服务。模型输出是整理结果，建议结合视频核对。

固定权限：本地存储、原生侧栏、B 站视频与字幕域名、读取页面信息和定位播放器，以及为扩展音轨请求设置 B 站 Referer 的请求头规则。音轨 CDN 和模型文件域名在用户开始识别时按需申请。自定义 AI 域名在保存或测试配置时单独申请。源码不包含真实 API Key，不加载远程脚本；语音模型仅下载数据，在本机识别。模型预览限制为文本排版、表格和安全链接；不允许输出中的脚本、图片、框架或链接追踪自动发起请求。API 请求不携带 B 站 Cookie，并拒绝重定向；字幕下载同样拒绝重定向并省略 Cookie，B 站信息接口仍使用登录状态。

本地保存不能防护已控制浏览器配置或操作系统的其他程序。所选模型服务仍能读取提交的字幕与元数据，需自行判断服务商可信度。停止请求可以终止本地等待和后续请求，但无法撤销服务端已处理的请求或保证不计费。

## 视频画面字幕

在「视频字幕」页点击「在视频中显示」，当前带时间轴的字幕会跟随播放器播放、暂停和跳转显示；再次点击可关闭。支持 B 站字幕、SRT / VTT 导入字幕和带时间轴的本地识别结果。纯 TXT 无法同步显示。切换来源会替换画面字幕，切换视频或分 P 会清理旧字幕。

画面使用浏览器原生字幕轨道。如果播放器自身也开启了字幕，可在播放器中关闭原字幕以免重复。运行 `npm run test:subtitles` 可验证字幕注入、来源替换、播放器替换和导航清理。

## 0.1.15 视频字幕显示与音轨时长兼容修复

新增「在视频中显示」开关，支持带时间轴的 B 站字幕、导入字幕及本地模型识别结果随播放进度显示。修复视频末尾比独立音轨更长时，误报「音频时长与当前分 P 不一致」的问题。从当前 CID 获取并验证的音轨允许有限末尾时差，字幕和识别进度按实际音轨时间轴计算；导入音频继续严格匹配视频时长。完整性检查仍拒绝明显截断、解码缺口和提前结束。截图视频的真实 AAC 解码及相关测试记录见 [语音识别验证记录](docs/speech-review.md)。
