biliSum 0.1.6 Chrome 安装说明

源码准备：
从 GitHub 克隆或下载源码后，在项目目录执行 npm ci 和 npm run build（需要 Node.js 22 或更新版本）。
拿到 ZIP 安装包则直接解压。

首次安装：
1. Chrome 地址栏输入 chrome://extensions
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择项目内的 dist 文件夹，里面应直接包含 manifest.json。

安装目录：项目目录下的 dist 文件夹。
ZIP 安装包：biliSum-0.1.6-chrome.zip。请先解压，再加载包含 manifest.json 的目录。
最低 Chrome 版本：120。

旧版升级：
API 设置保留，0.1.3 / 0.1.4 / 0.1.5 升级到 0.1.6 可继续读取完整结果缓存。0.1.2 及更早版本的缓存标识不同，不会自动恢复；升级前请先导出重要结果。
替换旧安装目录中的文件，在 chrome://extensions 刷新 biliSum，再关闭并重新打开侧栏。
如果此前加载的就是本项目 dist，直接在扩展管理页刷新即可。

首次使用：
在拼图菜单中固定 biliSum，打开标准 B 站视频页，点击 biliSum 图标。
右上角齿轮填写 API 地址、API Key 和准确模型名称，保存配置。
首次保存或测试时，Chrome 会询问 API 域名访问权限。连接测试也会发送一次简短模型请求，按服务商规则计费。

使用变化：
- 顶部 GitHub 图标在新标签页打开项目仓库；悬停显示“GitHub · 求 Star”，支持键盘操作与深浅主题。
- 总结细腻程度滑条提供五档，共同控制下一次导图和 Markdown 生成。
- 导图完成后收起生成区。导图 / 大纲 / 分布三个视图可直接切换，无新增 AI 请求。
- 默认先看主题，可选择分支、展开层级、选择双向紧凑布局；专注阅读后按 Esc 返回。
- 导图支持滚轮缩放、拖动、缩放按钮和原始大小；SVG / PNG / Markdown 大纲下载始终包含完整内容。
- 分布图展示实际主题条目与层级数量，数量不代表视频时长或重要性。
- Markdown 支持渲染预览、源码、复制和 .md 下载。中断草稿会标明未完成，可单独下载。
- 表格铺满文档，字号与正文一致，补齐单元格内边距和行列分割线；宽表独立横向滚动，支持左右方向键。已有总结重新打开即可使用新样式，无需重新生成。
- 字幕支持语言选择、搜索、时间跳转、导入 TXT / SRT / VTT / JSON、TXT / SRT 下载。
- 下拉框、输入框与组合搜索框使用统一样式，支持深浅主题。

AI 请求与错误恢复：
同一 API 源串行处理，最小起始间隔 3 秒，多个侧栏共享队列与限流冷却。
短字幕一次请求；长字幕逐段整理，成功笔记在当前侧栏内最多保留 30 分钟，重试或生成其他格式时可复用。
每次最终生成仍会请求模型并可能计费；关闭侧栏、过期或缓存淘汰后会重新读取。
生成统一使用流式接收；导图和分段笔记积累完整正文后才校验使用，思考内容不会显示或存入结果。
等待响应最多 180 秒，响应后连续 90 秒无数据会停止，单次请求总时限 10 分钟；连接测试最多 30 秒。
HTTP 429 遵循服务冷却时间，没有自动付费重试；排队、限流等待或生成中可停止。
HTTP 408 / 504 / 524 提示未收到完整结果及可能已计费，保留手动重试；脚本不会自动改用非流式重发。
刷新或语言切换失败会保留旧字幕与完整结果。缓存故障时可继续查看和下载。
未完成草稿只在当前侧栏内保留，关闭侧栏或换视频前请下载。

数据边界：
API Key 以普通字符串存于本机扩展存储，不是加密保险库。
生成时视频信息和字幕会发送到你配置的模型服务；本项目不使用额外中转服务。
停止能阻止本地等待和后续请求，不能保证服务端已处理的请求免计费。
本轮使用模拟 API 做回归，未使用真实账户或付费模型。
详细验证记录：docs/robustness-review.md。
