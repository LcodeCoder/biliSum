# 0.1.13 工作台与字幕来源验收

日期：2026-10-13。测试使用生产构建、独立 Chrome for Testing 会话及本地模拟浏览器 / 字幕 / AI 响应。真实课程音轨和模型转写的证据另见 [语音识别验证记录](speech-review.md)。没有读取个人浏览器配置或发送付费 AI 请求。

## 字幕归属与来源切换

- player 请求同时传 BV、AV、CID，接口返回的视频身份或分 P 不匹配时尝试备用端点，均不匹配则拒绝。已绑定轨道在下载前再次检查身份，时间超出当前视频则拒绝。
- 本地识别缓存按 BV、CID、语言、引擎及完整音频时长验证。恢复后，即使 player 接口新增有效身份但内容不同的字幕，也只加入候选列表，不下载、不覆盖当前本地结果。
- 刷新保留本地识别或导入字幕。手动选择 B 站轨道才替换，并清掉原来的恢复提示；本地候选继续可选。
- 来源切换根据字幕哈希恢复匹配的资源，不调用 AI。切换视频或分 P 清理旧本地候选；取消、错误、过时的异步响应不替换当前字幕和结果。
- 导入字幕保留在当前侧栏会话中，刷新可继续使用；关闭侧栏后不自动恢复导入文件。

这里验证的是视频身份和来源流程。接口身份及字幕时长正确不代表能证明文字的语义归属；原视频是核对内容的依据。

## 界面与交互

使用 Svelte 5 与 Bits UI 2.19.5 Tabs。宽窗口的左侧保留来源、资源状态和就地生成动作，右侧查看所选资源；窄侧栏把生成动作放为一行文字按钮，给阅读区域留出空间。浅色、护眼与深色共享统一控件和状态色，减少动态效果设置会关闭非必要动画。

浏览器检查覆盖：

- API 设置的保存、连接测试、失败恢复、关闭后取消待授权请求。
- 资源详情切换不生成内容，Tab / 方向键 / Home / End 导航与面板关联正确。
- Markdown 章节搜索、定位到真实标题、无匹配提示、查看全部和返回顶部；字幕搜索、清空、无匹配恢复、分页、时间跳转与下载。
- 导图三种视图、主题筛选、层级切换、节点展开、鼠标拖动、触摸取消、键盘平移 / 缩放、视图切换保留阅读位置，以及 SVG / PNG / 大纲导出完整内容。
- HTML 独立生成、三种样式、长文阅读、就地重排、离线目录、完整下载、预览释放及失败重试；本地版式切换不发送 AI 请求。
- 加载、无视频、无字幕、无搜索结果、错误、生成取消与离线状态；离线保留已完成内容和下载，正在生成的 Markdown 保留未完成草稿。
- 来源切换、视频 / 分 P 切换、刷新失败保留资源、异步来源校验和共享请求队列，不发出过时或重复付费请求。
- 三种外观、280 / 320 / 380 / 720 / 1164px 宽度、短窗口、普通与专注阅读；无横向溢出，导图和 HTML 使用剩余工作区高度，Esc 返回并恢复焦点。

## 结果与截图

- `npm run check`：0 错误、0 警告。
- `npm test`：127 项通过。
- 浏览器：60 项用例通过。完整运行 59 项通过，唯一失败为旧缓存提示的文案断言；更新到“当前分 P”的提示后单项复测通过。另行针对来源保护、导入保留、语言失败回滚、画布高度与短窗口做过复测。

- 浏览器回归逐场景检查未处理异常及外部请求；模拟页面不访问真实字幕或模型服务。
