# 0.1.13 无字幕视频识别验证记录

日期：2026-10-13；补充验证：2026-10-14。工作目录：`biliSum`。使用独立测试浏览器配置，没有读取个人浏览器数据或调用付费 AI 服务。

## 最终流程

首次读取没有本地缓存时使用 B 站字幕。恢复本地识别缓存或采用导入字幕后，自动刷新只更新候选来源，只有用户手动选择 B 站轨道才替换；可在同一个视频分 P 内切回本地来源。切换视频 / CID 清理旧来源。用户主动识别时，以当前 BV 和 CID 获取新的独立 AAC 音轨，常规播放接口失败后尝试 WBI 播放接口，优先选较小音轨并保留备用地址。下载请求省略 Cookie，仅接受指定 CDN 的 HTTPS 地址；请求头规则仅作用于扩展自身发起的音轨请求。

识别前确认音频起点、格式及总时长，音频与当前分 P 时长允许 2 秒编码 / API 取整误差。压缩文件不超过 128 MiB、总时长不超过 4 小时；按 25 秒核心窗口解码到 16 kHz 单声道，模型窗口两端保留最多 2 秒重叠。检测明显解码缺口及提前结束，不把整段长音频展开为 PCM。

自动模式只选择已可用的浏览器本地识别，否则使用 Whisper Base。浏览器内置识别明确设置 `processLocally` 并传入音频轨道，等待开始事件后播放样本；自动模式和明确选择内置识别时，失败都会丢弃前次全部文字，从头使用 Whisper。Whisper 使用独立 Worker、量化模型、单线程 WASM。浏览器内置没有精确时间轴，按无时间轴文本处理；不导出 SRT 或启用时间跳转。

只有音频覆盖到结尾且有可用文字才返回完成标记。取消、超时、线程错误或分 P 切换释放任务资源，不采用部分结果。替换字幕前保留用户当前的字幕和生成资源；完成后通过现有来源哈希与原有资源生成逻辑连接。

从视频音轨获得的完整字幕按 BV、CID、语言和识别引擎缓存，限制 12 条、2 MB UTF-8 预算，并与 AI 结果缓存分开。持久化失败仍可查看、生成和下载。导入音频不保存为视频转写缓存。

## 高数 P3 整段实测与故障修复

2026-10-13，在 Chrome for Testing 的隔离配置中加载实际扩展，验证 `BV1gA411j7Ta` P3，aid `330107670`、cid `247674804`，分 P 为“01.函数与极限第一节 映射与函数 01”。使用真实播放接口、CDN 音轨、扩展 DNR、Mediabunny 解码和 Whisper Base q8 WASM，保持生产 CSP；测试副本预先授予音频与模型域名权限。

真实音频时长 1814.4846875 秒，73 个窗口全部正常结束，生成 570 条 SRT，最后到 `00:30:14,485`。当前设备耗时 262 秒，浏览器没有未处理错误。人工查看开头及课程片段，内容为这节高数课程，并存在模型错字、简繁变化；不是新闻或餐费对话。测试结果和完整课程转写仅留在临时目录，没有把课程音频、全文字幕或临时签名 CDN 地址加入仓库。

两个复现问题与修复：

1. Whisper 把每段输入填充到 30 秒，29 秒真实音频可以返回 29.32 秒时间戳。旧检查按真实时长直接拒绝，约 1:40 处失败。现在先校验 30 秒模型窗口，再裁剪到真实边界并删除纯填充区字幕；此次有 7 个窗口实际需要裁剪。负数、倒序和超过模型窗口的时间戳仍拒绝。
2. Transformers 时间戳 seek 循环可能反复解码窗口尾部，约 8:20 处触发超时。现在显式限制一次解码，设置 token 上限并通过 EOS 验证正常结束，触顶而未结束的结果不标记为完整；2026-10-14 的补充修复会拆成较短片段重试，持续失败才报错。

识别后完成 Markdown / 导图 / HTML 流程、字幕下载及重载缓存恢复。三种 AI 资源使用测试响应，未用用户密钥调用真实付费服务。

另外复现并修复“提示已恢复，但来源变成中文”的界面缺陷：恢复本地缓存后原流程继续下载 B 站轨道并无条件覆盖，旧成功提示却未清除。现在刷新保留本地来源，只更新可选轨道；来源选择明确区分 B 站、本地识别和导入字幕。浏览器回归专门让合法身份的 player 接口返回不同内容，确认刷新 / 重载不下载或覆盖本地字幕，手动切换才下载，切回恢复相应资源，换 P 不保留旧来源。

接口身份校验不能验证字幕文字在语义上是否属于该视频。匿名查询这个 P3 的真实 player 接口返回正确 aid / BV / CID，字幕列表为空；未把用户截图中陌生字幕的服务端原因认定为已经定位。

## 2026-10-14 内置识别中断与本地解码修复

明确选择浏览器内置识别时，`aborted` 等失败也会自动从头使用本地模型。失败的内置结果整份丢弃，取消仍立即停止。点击识别时同时请求模型下载域名权限，以便运行中回退；内置语言包不可用时直接走本地模型。内置模式的缓存恢复也接受完整的 Whisper 回退结果，保持识别偏好并避免重开侧栏后再次识别。

Whisper 达到 440 个解码 token 后，只有真实生成的 EOS 才证明该次识别正常结束。缺少 EOS 时丢弃截断文本，将音频对半拆分并在边界两侧各保留 0.8 秒重叠，再依次识别；字幕按各片段负责的时间区间筛选、合并，并还原时间戳。音频短至 4 秒仍未正常结束时才报错，避免持续重试。模型运行异常直接报错；任一子片段失败都不返回部分字幕。下载 / 加载错误与推理错误采用不同提示。

音频面板、API 设置、导图、阅读页及空状态删除重复说明。识别选项保留为“自动 / 本地模型 / 浏览器内置”，详细限制放在控件悬停提示中。API 设置继续显示补全后的“请求地址：https://api.lcode.store/v1/chat/completions”。

## 实测边界

当前设备未安装 Edge，没有完成 Edge 真机测试。Chrome 原生本地识别的 API 及语言包可用状态已检测，真实语言包识别未完成联测；该路径的播放轨道、失败回退及 TXT 限制由测试替身验证。跨浏览器的已验证实现是 Chromium 上的本地 Whisper 路径，具体浏览器的解码能力或内存不足会报错并允许改用导入字幕。

模型可能出现简繁体变化、错字、漏字和时间偏差。受限视频、登录状态、B 站风控或不提供独立音轨的内容可能无法自动下载；此时保留音频文件和已有字幕导入入口。所有转写和 AI 资源均建议结合原视频核对。
